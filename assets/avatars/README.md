# Writer Persona Avatars

Profile avatars for the SEO writing / blogging team personas. Each persona has two
variants: a white-background version and a black-background version, in the same
studio-headshot style.

Batch 1 (personas 1–11): 512×512 JPEG, close-up headshot framing.

Batch 2 (personas 12–61): 1080×1080 PNG, zoomed-out chest-up framing with
headroom, bright high-key lighting, and ~1% per-pixel film grain so the portraits
don't read as AI-generated. File naming: `<first>-<last>-<title-slug>-<white|black>-with-noise.png`.
