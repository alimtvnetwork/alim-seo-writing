# Infographic philosophy: Vibe Coding Is Dead: A New York Engineer's Field Notes

## Central metaphor
A magician's top hat on a Brooklyn stage, split down the middle: the left half spills stage props (silk scarves, playing cards, a collapsing wand) labeled "the demo"; the right half reveals clockwork gears and ledger books labeled "the production system". One idea: tricks entertain, systems endure.

## Evidence pairs
- Perception vs stopwatch: developers predicted AI tools would make them 24% faster, yet the METR July 2025 randomized trial across 246 coding tasks measured them 19% slower (scope: professional developers, controlled trial).
- Confidence vs correctness: December 2025 analysis of 470 open-source pull requests found AI co-authored code carried ~1.7x more major issues and 2.74x more security vulnerabilities than human-written code (scope: open-source PRs, CodeRabbit analysis).

## Engineering channel
The visual shows the RISEUP ASIA LLC method as the antidote panel: problem (demo-grade code in production), data (the two evidence pairs above), evaluation (code review, ownership, on-call accountability), cost (premium engineers vs the rework tax), accountable owner (a named senior engineer, not a prompt).

## Color behavior
Deep charcoal background (#090611 family) for the stage; warm amber for the trick side; cool steel blue for the production side; neutral off-white for labels. No promotional gradients. Red reserved for the vulnerability stat only.

## Typography
Display type only for the 4 large factual labels (19% slower, 24% predicted, 1.7x issues, 2.74x vulnerabilities). Area text (DUMBO Brooklyn, New York) and keyword text (vibe coding, AI coding tools, software engineering) set in readable serif at Medium width, minimum 16px equivalent.

## Constraints
Legible margins on all sides; no unsupported rankings; no logos; every number carries its source and scope; the rhetorical payroll question appears as text, never as a fabricated figure.
