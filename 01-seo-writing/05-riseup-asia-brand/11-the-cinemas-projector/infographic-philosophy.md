# Infographic philosophy — The Cinema's Projector

Visual philosophy: a projection booth rendered as an editorial discipline. Warm paper backgrounds, deep navy ink, brass accents like the glow through a reel. Every graphic contrasts the chalkboard's memory with the platform's guesses, and keeps generous empty space so each comparison lands like a title card. High contrast, system type, nothing decorative that does not earn its place.
