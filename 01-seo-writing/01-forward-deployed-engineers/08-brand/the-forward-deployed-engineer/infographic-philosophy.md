# Infographic Philosophy — The Forward Deployed Engineer

The story argues that deployment, not model choice, decides whether AI spending turns into production value. The 3 infographics each carry one load-bearing idea from the piece, so a reader who only sees the images still absorbs the thesis.

## Infographic 1 — the stat card (95%)

A single number dominates: 95% of enterprise GenAI pilots deliver no measurable return. The number is set enormous because the story's entire argument leans on it; everything after is commentary on that gap. The sub-line ($30-40B in enterprise spending) supplies the scale of the waste, and the source line (MIT Project NANDA, 2025) is printed in full so the figure is traceable, not decorative. High-contrast navy on white keeps it readable at thumbnail size.

## Infographic 2 — the compare card

Two columns, red versus green, translate the story's compare/contrast section into a glanceable verdict. The left column (THE AI-SPENDING PATTERN) lists the four failure behaviors with red X marks; the right column (THE ENGINEER-LED PATTERN) mirrors each with the engineering discipline that replaces it, marked in green. The pairing is deliberate: each row is a before/after of the same decision, which is exactly how the story frames the choice facing buyers. Short labels, generous line spacing, zero overlap.

## Infographic 3 — the ranking card

The story's numbered ranking is reproduced with its editorial criterion stated up top ("what moves a system from pilot to production"), because the ranking only means something with its scoring rule attached. Navy number badges give the 5 entries a clear order, each head-line in bold with a one-line WHY beneath it. The card mirrors the article's list 1:1 so the two reinforce each other rather than competing.

## Shared design language

All 3 use the same 1200x630 canvas, navy header band with the story title, system sans-serif type, and the "RISEUP ASIA LLC · story series" footer. The palette (navy, slate, red/green accents) stays consistent across the series so the 100 stories read as one collection.
