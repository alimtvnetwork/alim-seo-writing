# 26 — Background & Typography Design Spec

**Purpose:** Design language for article/social backgrounds and the fonts that
sit on them, derived from three real source assets in this repo.

**Source assets** (all in `../../assets/backgrounds/`):

| # | File | Look |
|---|------|------|
| 1 | `pixheads-purple-bg.png` | Dark purple gradient, giant soft triangle watermark, tiny star specks |
| 2 | `blitz-dark-grid-bg.png` | Near-black, faint grid lines, soft radial glow in the centre |
| 3 | magnet-board reference | Light airy pinstripe paper, candy-coloured rounded cards, bold rounded sans headlines |

**Files in this spec:**

- `01-background-inventory.md` — what each source background is, measured and described
- `02-background-ideas.md` — background concepts to build from them
- `03-font-ideas.md` — font families and pairings inspired by the sources
- `04-usage-guidelines.md` — how to pair backgrounds and fonts without breaking contrast

**Rule of thumb:** dark backgrounds carry bold display type; light backgrounds
carry rounded friendly type. Never put thin text on a busy background —
flatten or scrim first.
